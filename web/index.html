What am I looking at?

This board watches your Claude Code sessions across every machine and tells you, at a glance, which ones need you and how much runway each has left. Swipe between scenes, or use the bar at the bottom on a monitor.

The Triage board

Needs you
Sessions waiting on your input (a question, a permission, a choice). These float to the top so nothing stalls unseen.
working / waiting / idle
working = Claude is actively going. waiting = it asked you something. idle = quiet, nothing pending.
The % and bar
How close that session is to an auto-compaction (where older context gets summarized away). 100% = Claude Code compacts — this matches Claude Code's own indicator. Hover the % to also see how full the raw context window is.
⏱ ETA
Estimated time until this session hits compaction at its current growth rate — your runway before context gets squeezed.
~N left
Approx tokens remaining before compaction.
▸N
Number of subagents this session is currently running.

🧠 Context health — the "dumb zone"

Two different things can go wrong, and they're not the same. One is running out of window — you hit the wall and Claude Code auto-compacts, summarizing older context away; that's the % number on each session. The other is the dumb zone: as a session piles up context, models miss details, repeat work, and drift — well before the window is full. The 🧠 pip tracks that second risk by how much context you're actually carrying, not how full the window is.

A warm 🧠 does NOT mean you're about to compact. On a 1M window you can be deep in the dumb zone at ~20% full. The fix there isn't urgency — it's a clean checkpoint (/compact or /clear) when it suits you.

🟢 Sharp
Plenty of headroom — Claude is at its sharpest.
🟡 Good
Healthy. Keep going.
🟠 Drifting
Dumb-zone onset. Older details may start slipping — wrap up sub-tasks or plan a /compact when convenient.
🔴 Deep
Lots of accumulated context may be dulling responses. /clear or /compact restores focus. (This is about clarity, not the window wall.)
⛔ Auto-compact
Separate signal: the % hit the window wall and Claude Code is summarizing older context away on its own.

Why absolute size, not %? On a 1M window, 20% is ~200k tokens — already plenty to start drifting. The window limit isn't the quality limit. Compacting or clearing at a good checkpoint keeps you in the green. (Grounded in Context Rot, Chroma 2025; Lost-in-the-Middle, Liu 2023 — a research-informed heuristic, deliberately soft: your own tool-error history shows no hard knee. Toggle off in the menu if you prefer the raw number.)
